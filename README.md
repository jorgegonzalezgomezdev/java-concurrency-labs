# Java concurrency labs

Maven projects on threads and concurrent programming in Java.

| Project | What it shows |
|---|---|
| `01-Hilos-Numeros-Letras` | Creating and coordinating threads |
| `02-Tienda-Dependientes-Clientes` | Producer/consumer simulation (shop assistants and customers) with thread-safe queues and `synchronized` |
| `04-Debug` | Debugging multithreaded code |
| `05-Executor-WriteCSV` | `ExecutorService` thread pools writing results to CSV |

Open each folder in IntelliJ (File → Open on the folder with the `pom.xml`).

Built during the *Services and Processes Programming* module (Multiplatform App Development, Nebrija, 2026). Original notes in Spanish: [README.es.md](README.es.md).
